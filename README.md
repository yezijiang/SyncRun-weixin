# 同频跑（TONGFIN RUN）

> 跑起来，遇见同频的人。

LGBTQ 专属的同城跑步社区，微信小程序（原生框架 + 云开发），首发深圳。

连接发生在跑道上，不是滑卡和私聊里。

## 两条底线

1. **安全感优先于增长。** 这个产品里用户不来的第一原因不是「没人」，是「来了会被看见」。
   不拉取微信头像昵称、分享卡不带品牌、屏蔽双向不可见——这些不向任何指标让步。
2. **打卡人数不证明「不孤单」。** 北极星是月度线下同跑人次与固定跑伴对数。
   打卡涨但线下为 0，就是定位失败。
