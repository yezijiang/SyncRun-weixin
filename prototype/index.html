可交互的部分

  1. 五个 Tab：发现 / 去跑 / 跑友 / 动态 / 我的，可自由切换
  2. 核心链路：发现 → 加入今晚场 → 去跑页出现"已加入"状态卡 → 跑完打卡 → 填数据生成配速 → 成功页（你的主链路）
  3. 状态联动：加入场次后，首页和去跑页的按钮会同步变成"已加入"
  4. 反馈类：给跑友加油、动态的「鼓励」计数、筛选 chips、城市卡片提示
  5. 跑友页四个入口：右上角／搜索栏 搜索（活动/跑友/队伍三档切换）→ 右下角＋发起组队 → 队伍卡上的 加入队伍 → 邀请（分享卡片 + 带参太阳码）
  6. 打卡 OCR：打卡页点「上传」会模拟 OCR 识别，自动回填距离和时长
  7. 双层表达（新）：跑友页 → 队伍卡「邀请」→ 顶部切换 对外分享卡片 / 站内邀请页，对比外层中性与内层专属

隐私约定：全站头像均为按 openid 生成的彩虹几何头像，不拉取微信真实头像与昵称；所有数据口径为「今天/累计」，无实时定位。这两条是「专属社区」定位下的强制设计，见 PRD 第 9 章。

数据全部为 mock，但口径与 PRD 一致：所有数字都是「今天/累计」，没有任何实时定位或实时在线状态——这正是纯小程序方案能做到的边界。
