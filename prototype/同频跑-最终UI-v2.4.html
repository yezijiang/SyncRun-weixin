关于同频跑
同频跑
让每一次奔跑，都不必是一个人。
找到和你同一时段、同一频率的人。

🌈 我们的定位

  • 一个同城跑步陪伴社区：不是记录工具，不比配速，不排名次
  • 核心是异步同行：同一时段各自开跑，跑完回来打卡，就知道今晚有人和你一起跑
  • 面向所有跑步的人，尤其在跑步这件事上希望有伴、又需要安全感的人

💡 我们相信

  • 陪伴不需要同时同地——同一时段开跑，就已经是"一起跑"了
  • 安全感是前提，不是选项：默认不暴露你是谁、你在哪
  • 跑步没有门槛：不问配速、不比距离，跑起来就算数

🚫 我们不做

  • 不做实时定位与轨迹追踪——你不需要被找到，只需要被陪着
  • 不自动读取你的微信头像与昵称（用不用真头像，由你决定）
  • 不做排名与配速比较——这里没有快慢，只有同频

📊 「本时段 X 人同场开跑」是怎么算的

这个数字 = 加入了同一开跑时段场次的报名人数。
它不是实时定位结果——我们承诺不使用实时定位，也无法知道谁此刻真的在跑。
到点了大家各自开跑，跑完回来打卡，就能看到今晚和你一起跑的人。

v2.4 品牌名与首页便签

  1. 品牌名定为「同频跑 pride running 🌈」：中文名保留「同频跑」——三个字自带语义，搜得到、记得住；纯音译名看不出产品是做什么的。英文名 pride running 负责圈内身份表达，只出现在站内与传播物料，不进工商
  2. 新手引导可返回 + 三步都有跑与彩虹：第 2、3 步原本只有抽象图标（圆点与线条 / 盾牌），既看不出是跑步产品、也没有品牌色。现在三步图标统一为「跑者剪影 + 彩虹跑道弧」；并补齐返回能力——顶部返回箭头、底部「上一步」按钮、进度圆点可点击跳转、右上角显示「2 / 3」进度
  3. 首页抬头改为欢迎语：品牌区现在是「欢迎来 同频跑 pride running 🌈」——「欢迎来」作浅灰小字前缀，中文名保持 17px 粗体主名，英文名 11px，末尾彩虹 emoji；下方仍是双语 Slogan 两行
  4. 品牌便签浮层：米黄便签纸质感（微旋转 + 胶带装饰），文艺清新的品牌介绍，写明 LGBTQ+ 与女性友好、遇见同好、互相鼓励、运动不孤单
  5. 它是浮层，不是页面内容：浮在首页之上（半透明遮罩 + 居中便签），点遮罩或 ✕ 收起，不随页面滚动、不占版面。首次走完引导后自动浮出一次
  6. 可控：安全中心「进入时浮出品牌便签」开关（公共场合不想被看到时可关）+「重新看看这张便签」入口；便签上还有「了解这个社区」直达关于页

v2.3 欢迎页重构（体验反馈）

  1. 问题：原来的「使用前请确认」是法务式页面——大段条文、三条风险提示、必须勾选，冷、有压迫感、让人担心
  2. 改法：把它从「风险告知」改成「我们为你做的事」。同样的合规内容，用承诺的语气讲：
    · 你的位置，只属于你
    · 你是谁，由你决定
    · 跑你自己的节奏
  3. 视觉：顶部彩虹跑道插画 + 欢迎语；三张柔和色卡片（珊瑚红/暖琥珀/柔绿）各带图标；勾选区改为轻卡片；法律必需的免责内容缩为底部小字，不再抢视线
  4. 文案：按钮「同意并继续」→「进入同频跑 →」；勾选「我已阅读并同意…」→「好，我知道了 —— 也同意…」；未勾选提示改为「先点一下上面那行小字就好 🌱」
  5. 合规未削弱：位置承诺、运动风险提示、未成年人条款全部保留（在卡片与底部小字中），勾选动作仍是进入的前置条件

v2.2 三点补充

  1. 「同场开跑」不是实时定位：数字来自加入了同一开跑时段场次的报名人数，是"约好一起跑"的约定，不是实测。Hero 明确标注"按开跑时段与报名人数推算 · 不使用实时定位"，数据说明写进「关于」页
  2. 集合点是地图选点，不是获取当前位置：新增地图选点界面——可搜索地点名、选附近推荐、没匹配时直接用输入的名称；背后调用 wx.chooseLocation（真实能力还支持拖动地图）
  3. 新增「关于同频跑」理念页：定位 / 宗旨 / 愿景 + 我们相信（3 条）+ 我们不做（3 条，体现克制）+ 数据口径说明。入口：首页「了解这个产品」、新手引导、设置页

v2.1 系统校正（挑剔复盘）

  1. 修正逻辑硬伤：删掉「此刻正在奔跑 / 此刻有 N 位跑友正在奔跑」——我们不做实时定位，就无法知道谁"此刻在跑"，这是自相矛盾。改为「今天跑过的跑友 / 今天已有 N 位跑友完成打卡」，全部数据回落"今天/累计"口径
  2. 补齐冷启动空态：首页三块（跑友 / 场次 / 城市）与统计条在"新用户首日"下显示空态与引导按钮，而不是让用户面对一片空白
  3. 首次进入声明页：隐私政策 + 运动风险免责 + 未成年人提示，需勾选同意才能继续（运动类产品缺免责声明是硬伤）
  4. 消息可就地处理：加油可回一个、约跑邀请可直接接受、报名可查看报名者、取消可跳其他场次，消息中心不再是"只能看"
  5. 发起即引导邀请：发起陪跑成功后直接打开邀请页（太阳码 / 站内邀请），解决"发起了没人来"的冷启动死结
  6. 设置补充：新增「运动风险提示与免责声明」入口，可随时重看

v2.0 终版补全（主动补齐的 8 项）

  1. 消息中心：通知铃与我的页入口 → 鼓励 / 报名 / 取消 / 提醒四类消息，未读小红点、全部已读、点击跳转对应页；举报处理结果也会回传
  2. 安全中心：可见范围三档（同城 / 仅互动过 / 隐身）、允许被搜索、动态进同城流、陌生人可加油三个开关；黑名单管理与解除；一键隐身 24 小时
  3. 举报分级：分类（骚扰 / 虚假数据 / 广告引流 / 冒充 / 其他）+ 补充说明 + 「同时屏蔽 TA」，提交后 24h 处理并回传结果
  4. 跑友主页：点头像或卡片进入，含累计数据、最近打卡与分段条、可能同场、加油 / 约跑 / 举报，且不通知对方
  5. 动态评论：评论数可点开，支持发评论，评论数实时 +1
  6. 我的记录：周目标进度、本周跑量/次数/用时、记录列表与支持删除、补录入口
  7. 设置与隐私：四类通知开关、安全中心入口、导出数据、撤回定位授权、注销账号（二次确认 + 7 天可撤销）、关于（备案名 / 版本 / 社区规范 / 隐私政策）
  8. 新手引导：首次进入三步——产品是什么 / 怎么用 / 安全是默认设置，可跳过并在设置里重看

v1.13 我报名的活动
