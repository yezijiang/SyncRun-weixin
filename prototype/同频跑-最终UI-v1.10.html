v1.10 时间与距离输入自由化

  1. 时间三种输入方式：① 顶部自由输入框（可直接写「周六傍晚 6 点半」）② 横向滚动快捷选项（今晚 20:00 / 21:00 / 21:30、明早 06:00 / 06:30、周六 07:00 / 18:00、周日 07:00）③ 底部时间选择器：日期 + 时 + 分三列滚动，支持今天起 7 天、05–23 时、5 分钟粒度，确定后自动设置「开始前 1 小时」提醒
  2. 距离可自定义：备选项扩到 3 / 5 / 8 / 10 / 15 / 半马 21.1KM（横向滚动），并新增自定义输入框，可填任意距离（支持小数，如 7.5 / 12.8），填入后自动取消备选高亮，清空即恢复

v1.9 时长输入与 OCR 识别

  1. 时长改为 时:分:秒：三个分段输入框，冒号固定显示在中间，只需填数字；输满 2 位自动跳到下一格，支持只填分秒（时留 00），配速与成功页按总秒数计算（例 1:12:05）
  2. 成绩截图自动识别：上传后先显示「正在识别成绩卡…」，成功则展示识别结果卡（Keep 成绩卡缩略图 + 距离 / 时长 / 平均配速 + 置信度），并自动填入距离与时分秒；提供「重新识别」
  3. 识别失败降级：点「演示识别失败」可看降级路径——提示未识别并自动转手输，提供「换一张重试」；实际实现为置信度低于阈值时自动降级

v1.8 取消机制与细节

  1. 备案名一致性（判断）：小程序备案管的是「小程序名称 / 简介 / 服务类目」，页面内文案不属于备案名称；但为降低复查风险，头部英文副标已降级为 10px 灰色小字，中文「同频跑」为唯一主名称（如需彻底规避，可把英文名只放在「关于」页）
  2. 文案：首页主标语改为「此刻，不止你一个人在跑」
  3. 发起陪跑按钮彩虹化：改为彩虹渐变描边 + 极浅彩虹底 + 彩虹渐变文字，与左侧实心彩虹 CTA 形成「实心 / 描边」的层次，不抢主按钮
  4. 取消活动：发起人视角新增「取消这场活动」，确认弹层写明「N 位报名者会收到通知」，取消后全场显示「已取消」灰色态，按钮禁用
  5. 取消参加：已加入非发起人显示「取消参加」入口，确认后退出，其他人看不到「已退出」记录
  6. 报名人数可见：发起人视角新增「报名的人」卡片，含报名人数、已打卡数、每位报名者的加入时间与打卡状态

v1.7 定位与提醒

  1. 首页 CTA 比例调整：右侧「＋ 发起陪跑」加大到 118×58 并带上文字说明，与主按钮「开始我的跑步」并排
  2. 打卡一次性定位：打卡页新增「打卡位置」——点击才调用 wx.getLocation 读取一次，用于城市归属与点亮；明确不持续追踪、不上传轨迹、不展示精确坐标
  3. 集合点用地图选点：发起陪跑时「集合地点」改为调用 wx.chooseLocation 在微信内置地图选点，返回 POI 名称 / 地址 / 经纬度，大家到的是同一个具体位置；线下场未选点不可提交；只存集合点，不共享实时位置
  4. 开始前 1 小时提醒：发起面板默认开启「开始前 1 小时 · 微信订阅消息」，场次详情新增「提醒」卡（开始前 1h / 本场结束两个订阅），底部主按钮改为「⏰ 开始前 1h 提醒」

v1.6 发起入口重构

  1. 首页主入口：底部 CTA 右侧新增深色圆形「＋」按钮，一键发起陪跑；「正在发起的陪跑」标题右侧也有「＋ 发起 ›」
  2. 两类动作分开：发起面板顶部切换——发起一场陪跑（一次性：距离 / 时间 / 地点 / 配速 / 人数上限 / 线上异步 or 线下约跑）与 创建一个队伍（长期小圈子：队伍名 / 常跑距离 / 时段 / 入队方式），并写明两者区别
  3. 入口归属修正：去跑页按钮改为「＋ 发起一场陪跑」（原来只是一句 toast，点了没反应）；跑友页右下角 ＋ 直接打开「创建队伍」
  4. 发起后真实落库：新建场次立即出现在首页「正在发起的陪跑」与去跑页，自己自动加入，可直接进入场次详情

可交互的部分

  1. 五个 Tab：发现 / 去跑 / 跑友 / 动态 / 我的，可自由切换
  2. 核心链路：发现 → 加入今晚场（会引导订阅提醒）→ 跑完打卡 → 自动配速 → 成功页
  3. 状态联动：加入场次后，首页和去跑页按钮同步变为「已加入」
  4. 跑友四入口：搜索（活动/跑友/队伍）/ 发起组队 / 加入队伍 / 邀请（外层中性 vs 内层专属对比）
  5. 打卡 OCR：点「上传」模拟识别回填距离与时长
  6. 举报与屏蔽：跑友卡、动态卡的「···」→ 操作面板，屏蔽后卡片即时消失

隐私约定：全站头像均为系统生成的几何头像，不拉取微信真实头像与昵称；所有数据口径为「今天/累计」，无实时定位。
